# Limits and continuity

A limit describes the value a function approaches as the input approaches some
point. Write lim(x→a) f(x) = L when f(x) gets arbitrarily close to L as x gets
close to a (from both sides).

Key facts:
- The limit can exist even when f(a) is undefined (e.g. sin(x)/x at 0 → 1).
- One-sided limits must agree for the two-sided limit to exist.
- A function is continuous at a when lim(x→a) f(x) = f(a).

Common techniques: direct substitution, factoring, rationalizing conjugates,
and the squeeze theorem.
